## Draft PR #3 blocker re-audit

The remaining draft-review blockers were rechecked against the implementation rather than the PR
description:

- Verified Shop gating is one independent strict predicate. It accepts `in_stock`, `low_stock`, and
  `preorder`, but rejects incomplete identity/color/category data, malformed images, inconsistent
  image rights, stale or incomplete verification provenance, invalid prices, and missing affiliate
  disclosure.
- Catalog intelligence now includes `vibe`, `price_tier`, `accessory_subtype`, and
  `fragrance_family` in shared validation, server payloads, Add/Edit UI, and tests. Category derives
  the stored kind and incompatible category/kind combinations are rejected.
- DRIP accessory subtypes cover earrings, glasses, sunglasses, necklaces/chains, bracelets, rings,
  watches, hats/beanies, belts, bags, socks, scarves, wallets, and grills.
- Home excludes archived closet items from counts and recents. A Generate shortcut is absent until
  the safe 1/1/1 core is ready.
- The Verified-inventory-empty explanation takes precedence in Outfit Ideas as well as the product
  tabs.
- New catalog rows begin unverified. Description, material, fit, and metadata edits do not extend
  verification freshness; Verify/Reverify is a separate auditable action.

## Preserved invariants

- The Phase 2 migration still defines exactly 51 demo rows with the original IDs and
  `/catalog/phase-2/*.svg` image paths.
- All 51 project-owned Phase 2 SVG files remain unchanged.
- Feed/social privacy, closet privacy/RLS, account data, closet items, outfits, photos, and user
  content were not altered.
- `isVerifiedPurchasable()` independently enforces the complete purchase-safety contract, and
  `productActionFor()` continues to expose retailer actions only for products that pass it.
